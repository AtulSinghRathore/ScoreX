# ScoreX

ScoreX is a real live-sports score experience with **ScoreX Coin (SXC)** predictions. SXC is a virtual, non-transferable credit with no cash value. There are no deposits, withdrawals, purchases, transfers, or cash prizes.

## Live sports data

ScoreX now reads real match data from the free [SportScore API](https://sportscore.com/developers/), which was discovered through the [public-apis/public-apis](https://github.com/public-apis/public-apis) directory.

- Real live/recent/upcoming football, basketball, cricket, and tennis matches
- Scores, status, competition, team names, start times, and available logos
- Browser-safe HTTPS requests with CORS enabled
- No API key exposed or required
- Automatic refresh every 90 seconds
- Last successful real response cached locally for temporary provider failures
- Visible `Powered by SportScore` attribution, as required by its free-use terms

SportScore responses are cached at the provider edge for 60 seconds, so ScoreX does not poll more frequently than the data can change. Check the provider's current rate limits and terms before a high-traffic launch.

## SXC prediction layer

SportScore provides scores, not bookmaker odds. The multipliers shown by ScoreX are deterministic **virtual SXC multipliers generated by ScoreX**. They are not bookmaker prices or supplied by SportScore.

Included features:

- Live, upcoming, and results navigation
- Sport filters and manual score refresh
- Virtual market selection, prediction slip, stake controls, and open predictions
- Local SXC balance persistence
- Multiple browser-local admin accounts and roles
- Admin creation, deactivation/reactivation, market suspension, and local audit log

## Run locally

This build is static and has no dependency installation step:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Do not open `index.html` directly with a `file://` URL; use a local HTTP server so browser networking works consistently.

## Current architecture boundary

The real live-score feed works without a ScoreX backend because SportScore is CORS-open and requires no secret. User/admin accounts, SXC balances, predictions, and audit logs are still browser-local. Secure shared accounts across devices require the planned Cloudflare Workers + D1 backend.
